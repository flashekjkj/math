# 强模型生成分析标签

程序：math_tutor/data/teacher_analysis.py；使用用户指定的 deepseek-v4.1-flash 与 Base URL，不自动换模型。
只发送当前1000条训练题及其参考列式、参考值，不发送验证集、测试集或人工验证审核文件。

## 数据质量

生成简短教学分析：明确所求量、关键数量关系、比较基准、运算顺序。不输出冗长思考过程，不生成机械算式翻译。
同一模型另开独立请求，只看题目、候选分析与列式进行质检。参考不完整、多问缺答案、条件残缺或不确定可拒绝。
本地校验JSON、分析25至160字符、非机械模板、白名单表达式、计算结果与参考值一致。
两次模型请求都不保证绝对正确；这仍然是合成数据，不冒充人工金标准。参考引导可能产生偏差，需要在后续实验中验证。

## 文件

data/versions/teacher-analysis-v1/：
- records/：逐题生成结果、复核结论与拒绝理由，续跑时跳过已有结果。
- accepted.jsonl：保留ID与来源的通过记录。
- rejected.jsonl：拒绝记录；不强行修补后加入训练。
- preview.readable.json：前20条易读预览。
- sft_train/train.jsonl：分析＋列式的SFT目标，最终答案交给计算器。
- control_train/train.jsonl：完全相同通过题目与列式的“只列式”对照组，避免过滤题目造成比较混淆。
- usage.json：每次请求的模型返回用量、请求ID、返回模型；断线未知费用保留预留额。
- provenance.json：模型、URL、源文件哈希与提示词哈希，版本变化时拒绝混用。
- summary.json：通过/拒绝数量及本地累计用量。

## 用量

关闭thinking，单次最多512输出tokens，默认总预算800000，最多允许850000；请求前预留输入UTF-8字节数加输出上限和余量，返回后用usage结算。
预留为保守工程估计，不是厂商tokenizer或余额查询。缺usage、网络费用不明、HTTP错误时停止新请求，不自动重试。并发最多4。
不能从API确认免费额度的适用模型、余额或有效期；控制台为准。若还有其他程序同时用额度，本程序无法统计那些调用。

## 续跑（Anaconda Prompt中先启动PowerShell）

```powershell
conda activate math
cd E:\desktop\LLM_Project\math-tutor
$secure = Read-Host 'API Key' -AsSecureString
$env:DASHSCOPE_API_KEY = [System.Net.NetworkCredential]::new('', $secure).Password
python -m math_tutor.data.teacher_analysis --limit 1000 --workers 3
Remove-Item Env:\DASHSCOPE_API_KEY
```

密钥仅放进程环境，不写代码、配置或结果。不要把密钥写进命令历史。
已拒绝项不会自动重试；如需修订提示或重新生成，使用新的数据版本，并累计已有消费，避免重复计费。

本轮只生成数据，不启动训练。训练前还需统一验证输入提示、检查训练标签与长度，并做同一批题的“只列式”和“分析＋列式”对照。
