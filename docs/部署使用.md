# 部署与网页演示

训练产出（合并模型或底座+adapter）通过一套服务层对外使用：网页聊天界面 + OpenAI 兼容 API。
0.5B 模型 FP16 约 1GB 显存，4GB 笔记本即可运行；与训练共用同一环境，不要同时跑训练与推理服务。

## 安装

部署依赖是最小集合，在训练环境基础上附加安装（不改变训练依赖）：

```bat
python -m pip install -r requirements-serve.txt
```

## 启动网页演示 + API

```bat
cd /d E:\desktop\LLM_Project\math-tutor
python -m math_tutor serve --model models/math-sft-0.5b
```

浏览器打开 http://127.0.0.1:8000 即可对话。页面支持：

- 提示词模式切换：解题模式（prompts/solve.txt）/ 辅导模式（prompts/tutor.txt）
- 多轮对话与清空历史；Enter 发送，Shift+Enter 换行
- 流式输出，每条回复下方显示首字延迟、总耗时与生成速度
- 顶部显示模型来源、设备与显存占用

加载底座+LoRA 而不合并权重（对比新 adapter 时用）：

```bat
python -m math_tutor serve --model models/qwen-0.5b --adapter runs/local-sft-v1 --port 8001
```

## OpenAI 兼容 API

| 接口 | 说明 |
|---|---|
| `GET /health` | 设备、模型路径、显存占用 |
| `GET /v1/models` | 模型列表 |
| `POST /v1/chat/completions` | 对话补全，`stream:true` 时为 SSE 流式输出 |
| `GET /api/prompts` | 网页使用的提示词 |

非流式：

```bash
curl http://127.0.0.1:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"math-tutor","messages":[{"role":"user","content":"1+1=?"}],"stream":false,"max_tokens":128,"temperature":0}'
```

流式（`data:` 行为 OpenAI 格式 chunk，以 `data: [DONE]` 结束）：

```bash
curl -N http://127.0.0.1:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"math-tutor","messages":[{"role":"user","content":"小明有3个苹果，又买了5个，一共几个？"}],"stream":true}'
```

服务本身无状态，多轮对话由客户端回传完整 messages 历史；输入超过 2048 token 会返回 413 错误而不是静默截断。

## 推理基准

```bat
python -m math_tutor benchmark --model models/math-sft-0.5b --runs 3
python -m math_tutor benchmark --model models/qwen-0.5b --adapter runs/local-sft-v1 --output results/benchmark-adapter.json
```

输出 JSON 报告（results/ 下，不覆盖旧文件）：模型加载耗时、显存占用、预热耗时、每次运行的首字延迟、总耗时与 tokens/s。本机实测（RTX3050 Laptop 4GB，0.5B FP16 合并模型，贪心生成）：

| 指标 | 数值 |
|---|---:|
| 模型加载 | 16.6 s |
| 显存占用 | 0.93 GB |
| 首字延迟（纯生成） | 0.04 s |
| 生成速度 | 约 31 tokens/s |

## 常见问题

- 端口被占用：换 `--port`；不要重复启动第二个实例，4GB 显存放两份模型会 OOM。
- Windows 终端中文乱码：管道输出按 GBK 解码导致，落盘 JSON 均为 UTF-8，不影响网页与 API。
- 量化：4bit 方案见 `python -m math_tutor.tools.model_quant --help`（bitsandbytes，Windows 上需验证可用性）；GGUF 路线需要 llama.cpp 工具链，未纳入当前必做范围。
- 合并权重：`python -m math_tutor.tools.merge_peft_adapter --help`，输出目录不能覆盖原模型，合并前后用相同输入核对生成内容。
