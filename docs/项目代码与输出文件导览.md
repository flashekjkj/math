## 1. 推荐复习路线

先读 cli/common/launcher，随后 prepare 与 test_data，再读 scoring/runner 和 test_scoring，然后精读 supervised_finetuning 的预处理、LoRA 与 Trainer；接着 runtime/calculator/merge_fp16，最后读偏好构建、dpo_training 与服务层。GRPO/PPO 和上游通用工具作为第二轮。

主链：原始题目 → 清洗和 family 切分 → conversations → token/labels → SFT Adapter → 合并 SFT → 构建偏好 → DPO Adapter → 推理/计算器 → 逐题评测 → summary/审计。
