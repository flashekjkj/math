# GRPO 第一轮实验结果

训练完成：200道题，每题4个采样，1轮，200次优化器更新。
基础模型：`models/math-sft-0.5b`，与DPO运行记录的路径一致；本轮模型文件SHA256核验通过，未加载DPO Adapter。
训练奖励为 numeric-v2 最终数值正确性，未额外奖励格式。

| 模型 | 验证集正确数 | 数值正确率 | 解析率 |
|---|---:|---:|---:|
| SFT | 18/100 | 18.0% | 99.0% |
| DPO | 18/100 | 18.0% | 99.0% |
| GRPO | 18/100 | 18.0% | 99.0% |

三组本次重新生成，100题、同一数据哈希/提示词/greedy/192 token上限/评分器。

采样总数：800；获得正确奖励：127。
混合奖励组：41/200；无组内奖励差异比例：79.5%。
非零LoRA B张量：48；B矩阵总体L2范数：0.018104。
峰值CUDA已分配内存：1.19 GiB（不含所有驱动/显示占用）。

相对SFT逐题变化：`{"DPO": {"gain": 0, "regression": 0, "changed_response": 6}, "GRPO": {"gain": 0, "regression": 0, "changed_response": 2}}`。

数值正确率不能证明列式符合题意、推导正确或教学质量。纯正确性奖励有稀疏性；全对或全错组没有正确性相对优势。
本轮是小规模方法验证，不保证优于SFT/DPO。未以测试集调参。相同题池不表示DPO与GRPO算力预算相同。

完整证据见 `grpo-v1-evidence.json`；命令见 `GRPO训练说明.md`。

结论：本轮GRPO训练与权重更新均已验证，但在相同100题验证集上未观察到数值正确率提升，正确题集合也未变化。相比SFT有2条回答文本发生变化。79.5%的训练组没有正确性奖励差异，是有效学习信号偏少的直接证据；这不是唯一可能原因，不能仅凭本轮实验断言GRPO方法无效。
