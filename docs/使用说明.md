# 本地模型使用

在项目根目录激活 math 环境。混合多轮模型训练完成后使用：

```powershell
python -m math_tutor chat --model models/qwen-0.5b --adapter runs/multiturn-sft-v1 --system-prompt-file data/versions/multiturn-v1/system_prompt.txt --keep-history --max-new-tokens 192
```

该入口对每轮都使用同一微调模型与完整会话，不经过自动辅导规则路由。/reset 清空历史，/exit 退出。请求过长会明确报错，请重开会话。

逐轮测试命令与评审方法见 docs/多轮SFT实验.md。

原解题模型与计算器仍可使用：

```powershell
python -m math_tutor chat --model models/qwen-0.5b --adapter runs/local-sft-v1 --calculator-only --keep-history
```

计算器只能复算列式，不能保证列式符合题意。自动辅导模式包含规则路由与训练题参考，应与纯模型测试分别理解。
