## 常用命令

在项目根目录运行：

```bat
conda activate math
cd /d E:\desktop\LLM_Project\math-tutor
python -m math_tutor --help
python -m math_tutor check
python -m unittest discover -s tests -v
python -m math_tutor train --config configs/local.json --dry-run
python -m math_tutor chat --adapter runs/local-sft-v1
```

旧的python starter.py命令仍然兼容。starter.py只是入口，真正逻辑已分进包内，不依赖同级MedicalGPT。
已有local-sft-v1目录非空，直接再次训练会拒绝覆盖；每轮更改output_dir。

本地高级模块帮助：

```bat
python -m math_tutor.training.dpo_training --help
python -m math_tutor.training.grpo_training --help
python -m math_tutor.tools.merge_peft_adapter --help
python -m math_tutor.tools.validate_jsonl --help
```

运行本项目Python模块仍然是“独立项目”：会使用PyTorch、Transformers等库，也复用了本地保留来源的开源代码；不等于重新手写所有训练算法。

## 学习顺序

1. common.py与data/prepare.py：题目、方程、答案如何变为训练目标。
2. data/prepare.py的audit：实际token长度与完整样本保留。
3. training/supervised_finetuning.py的preprocess_function：提示位置为何mask为-100、回答如何监督。
4. training/launcher.py和configs：参数、有效批量、实验目录、代码与数据版本。
5. inference/runtime.py：底座+adapter如何共同生成。
6. serve/engine.py与serve/api.py：训练产物如何对外服务，SSE流式协议与OpenAI兼容格式。
7. evaluation/scoring.py：数值正确、未解析、冲突和待审核分别是什么意思。
8. tests：通过反例理解评测不能怎样“作弊”。
9. 之后才阅读DPO/GRPO/PT。工具目录中的词表扩展脚本是备用，不建议当前修改Qwen词表。

未修改个人Transformer练习的内容，原test.py放到了examples/learning/transformer_exercise.py，其中原有练习错误不属于本次项目测试范围。
旧根目录测试文件保留为兼容入口，正式测试位于tests/。

## 版本与许可

third_party/provenance.json记录实际从本地MedicalGPT工作区复制的文件、原哈希及适配后哈希，而不只依据提交号宣称源码无改动。
third_party/MedicalGPT-LICENSE保留Apache2.0条款，源文件保留版权头。
新训练输出保存本项目代码/数据哈希与依赖；历史run_config中的原路径是实验记录，不会因为重构而被篡改。
requirements.lock.txt是当前Windows环境快照，Linux租用服务器应先装匹配驱动的PyTorch，再验证主要依赖版本；不要直接复制整个Windows环境。
