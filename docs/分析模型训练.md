# 分析标签SFT实验

## 实际结果

固定200题测试：旧SFT原始48/200（24%），旧SFT＋计算器95/200（47.5%），机械关系说明＋工具调用42/200（21%），新教师分析＋列式＋计算器68/200（34%）。
新模型较旧SFT＋计算器低13.5个百分点；配对比较57题都正确、11题新增正确、38题退步、94题都未答对。
100题验证集答对35题（35%），列式可执行88题。没有以测试集结果继续训练或挑选检查点。
结论：本轮较机械模板有改善，但未超过当前最佳旧SFT＋计算器，不替换最佳版本。不能据此断言模型能力已到上限。

训练：configs/analysis-sft.json；954条教师生成并自动质检的“分析＋列式”样本，Qwen2.5-0.5B-Instruct基础模型，LoRA q_proj/v_proj r=8，学习率1e-4，1 epoch，120次更新，seed=42，FP16，长度384。
训练约671.95秒，平均train_loss=1.25248。目标文本变长且任务不同，不能与旧loss直接比较。
未使用算术专项训练。推理时只提取一份列式，由受限计算器执行，无需模型重复生成JSON调用。

旧验证集没有分析标签，本轮关闭不匹配的验证loss，训练完成后对固定100题验证集、200题测试集执行真实生成和工具评分。没有根据测试成绩选择检查点。

完整模型：models/math-analysis-0.5b；Adapter：runs/analysis-sft-v1。FP16合并后再评测。

比较基线包括原SFT原始答案24%、原SFT列式＋计算器47.5%、上一轮机械关系说明＋工具调用21%。
本轮954条过滤数据和提示、长度、输出协议均与历史1000条实验有差异，不是单独检验分析标签的严格消融。数值正确率属于模型＋工具系统，不等于分析文本正确率或模型独立计算准确率。
测试集已在历史实验中使用，本轮不是新的盲测。
